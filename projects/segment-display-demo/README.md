# 8 位数码管动态扫描练习

## 项目目的

把固定数值显示到 CT107D 的 8 位数码管，理解段码、位选和刷新周期的配合。

## 硬件平台

CT107D、IAP15F2K61S2、74HC138/74HC573 与 8 位数码管。Keil 工程目标为 `STC15F2K60S2 Series` 兼容系列，例程按 12 MHz 配置 Timer2。

## 实现功能与技术点

- `love` 初值为 `12345`；`Display_Task()` 将数值拆为十进制位，放入显示缓冲区，前 3 位留空。
- Timer2 中断轮流关闭位选、写段码、打开当前位，实现动态扫描。
- `library.h` 定义 `Control()`，通过 P0/P2 操作段选和位选锁存器。

源码入口：`main.c`；定时器与锁存器辅助：`library.c/.h`；Keil 工程：`2.2.uvproj`。

## 如何运行与验证

在 Keil C51 打开 `2.2.uvproj`，核对时钟与开发板后编译下载，预期观察到 `12345` 的稳定显示。原工程历史构建记录为 0 error / 0 warning；本仓库副本的板端显示效果尚待复测。
