# 8 位数码管动态扫描练习

## 一、项目背景

蓝桥杯程序经常要在 8 位数码管上同时显示测量值、参数和状态。P0 只有一组段数据，不能给每一位长期保持不同数字；这份练习先用固定数值 `12345` 把“段选 + 位选 + 定时刷新”跑通。

## 二、硬件分析

- CT107D 的 P0 是共享数据口，P2.5～P2.7 经 74HC138 选择锁存通道；`0xE0` 锁存段码，`0xC0` 锁存位选。
- 数码管按位轮流点亮。一个扫描周期内，每次只把当前位的段码和位选送出；扫描足够快时，人眼看到的是连续的 8 位内容。
- 板载 MCU 为 IAP15F2K61S2；工程目标为 `STC15F2K60S2 Series` 兼容系列，Timer2 配置按 12 MHz 写成。

## 三、软件设计

```text
main → System_Task（关闭无关输出、启动 Timer2）
     → Display_Task（把 12345 拆入 Bit[4]～Bit[8]）
Timer2_Service → 关位选 → 取 Code[Bit[count_dsp]] 写段码 → 开当前位
```

`main.c` 保存显示缓冲 `Bit[1..8]` 和段码表 `Code[]`；`library.h` 的 `Control(x, y)` 依次写 P0、P2、再释放 P2 选通。

## 四、关键代码分析

- `Bit[1]`～`Bit[8]` 表示 8 个位置，不是 GPIO 引脚号。前 3 位用 `OFF` 留空，后 5 位由除法和取模得到。
- `Code[]` 把数字索引转换成段码；`OFF` 对应不点亮。数据缓冲与硬件段码分开，日后换成温度、电压时只要更新 `Bit[]`。
- `Timer2_Service()` 的顺序是 `Control(0xC0, 0)` → `Control(0xE0, 段码)` → `Control(0xC0, 1 << (位号-1))`。先消影、后换段、再点亮当前位，是动态扫描的关键。

## 五、调试过程

- **问题**：切换数码管位时容易把上一位的段码带到下一位，形成重影。
- **现象**：这是扫描电路要处理的典型现象；当前仓库没有该工程的实物照片。
- **原因**：如果上一位仍导通就改写段码，两位会在短时间内显示混杂内容。
- **解决**：现有代码采用“关位 → 写段 → 开位”的更新顺序；本轮没有改动源码。
- **经验**：显示质量既取决于段码表，也取决于锁存顺序和 Timer2 刷新频率。

用 Keil 打开 `2.2.uvproj` 可编译该独立工程。原工程历史构建为 0 error / 0 warning；后续用板端照片记录亮度、闪烁与重影情况。

## 六、项目收获

这份练习把 `Bit[]` 显示数据、`Code[]` 段码转换和定时位扫描拆成三个层次。后面的 ADC、温度和竞赛训练工程继续使用这套显示思路。
