# LED 与锁存器练习

## 项目目的

从 CT107D 的 P0 数据口和 P2 选通信号开始，练习把 LED 输出、继电器控制和定时器节拍串起来。保留的是学习阶段的原始工程，不是重新设计后的驱动库。

## 硬件平台

CT107D、IAP15F2K61S2、LED、继电器和数码管。Keil 项目使用 `STC15F2K60S2 Series` 兼容目标；`library.c` 的 Timer2 配置标注为 1 ms / 12 MHz。

## 实现功能与技术点

- Timer2 中断更新 LED、继电器和数码管锁存器输出。
- `Logic_Task()` 按计数改变 LED 位置和方向，约 5 秒翻转一次继电器状态。
- 使用 P0 与 P2 选择 `0x80`、`0xA0`、`0xC0`、`0xE0` 通道，练习共享数据总线的使用方法。

源码入口：`main.c`；定时器初始化与类型定义：`library.c/.h`。打开同目录 `2.1.uvproj` 可查看原工程配置。

## 如何运行与验证

在 Keil C51 打开 `2.1.uvproj`，核对目标器件、12 MHz 时钟和板上设置后编译、下载。观察 LED 的位置变化、继电器状态和数码管输出。原工程历史构建记录为 0 error / 0 warning；本仓库副本尚未重新编译或实物复测。
