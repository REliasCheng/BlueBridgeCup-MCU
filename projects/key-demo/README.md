# 独立按键与 LED 响应练习

## 项目目的

练习把独立按键作为输入事件，再用 LED 给出可见反馈；同时观察轮询任务和 1 ms 定时节拍如何配合。

## 硬件平台

CT107D、IAP15F2K61S2、独立按键和 LED。Keil 工程目标为 `STC15F2K60S2 Series` 兼容系列；`library.c` 的 Timer2 初始化标注为 1 ms / 12 MHz。

## 实现功能与技术点

- `Read_4Key()` 读取独立按键，内部计数用于按下确认。
- `Key_Task()` 根据返回的键值选择对应 LED；Timer2 中断更新 LED 锁存器并累计扫描节拍。
- 从这个小工程可以看到输入采样、简单消抖与输出状态之间的关系。

源码入口：`main.c`；按键函数：`library.c/.h`；Keil 工程：`2.3.uvproj`。

## 如何运行与验证

在 Keil C51 打开 `2.3.uvproj`，核对按键接线、主频和目标器件后编译下载，分别按下独立键观察 LED 变化。原工程历史构建记录为 0 error / 0 warning；板端响应尚待复测。

## 调试问题与下一步

静态阅读发现 `Key_Task()` 中的局部变量 `key_value` 仅在 `Count_Key >= 1` 时赋值，但后面的判断会无条件读取它，存在未初始化值参与判断的可能。初版不改原始学习代码；后续先复现，再单独提交修订和测试结果。详见 [调试记录](../../docs/debugging-notes.md)。
