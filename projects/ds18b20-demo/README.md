# DS18B20 温度读取练习

## 项目目的

练习单总线温度传感器的读取，并把温度值显示在数码管上。

## 硬件平台

CT107D、IAP15F2K61S2、DS18B20、8 位数码管。Keil 工程目标为 `STC15F2K60S2 Series` 兼容系列；定时器初始化按 12 MHz 编写。

## 实现功能与技术点

- `onewire.c/.h` 负责 DS18B20 单总线通信，`main.c` 调用 `Read_Temp()`。
- Timer2 中断动态扫描显示；主循环约每 750 个节拍重新读取温度。
- 温度值转换为百倍整数后拆位显示，包含小数点位置处理。

源码入口：`main.c`；单总线驱动：`onewire.c/.h`；Keil 工程：`3.2.uvproj`。

## 如何运行与验证

在 Keil C51 打开 `3.2.uvproj`，确认主频、传感器连接和数码管设置后编译下载。记录室温显示和加热/冷却后的变化。原工程历史构建记录为 0 error / 0 warning；目前没有本仓库副本的实际温度曲线或照片。

## 调试问题与下一步

初始化代码会连续读取 100 次温度，用时和首次数值稳定性需要板端确认。若温度异常，应先核对单总线时序、上拉与时钟配置，再记录定位过程；初版不修改驱动源码。
