# UART 命令与数据输出练习

## 项目目的

用串口把板上的时间、温度数据输出到电脑，练习 UART 中断接收、简单命令识别和多外设协作。

## 硬件平台

CT107D、IAP15F2K61S2、UART1、DS1302 RTC、DS18B20 温度传感器。`uart.c` 注明 9600 bps / 12 MHz；Keil 工程选择 `STC15F2K60S2 Series` 兼容目标。

## 实现功能与技术点

- 串口接收中断把字节放入缓冲区；约 100 ms 没有继续接收时清空该帧。
- 收到 `time1` 后输出时间，收到 `temp2` 后输出温度。
- Timer2 负责毫秒计数；主循环处理 RTC 读取、温度采样与命令逻辑。
- `main.c` 是业务入口，`uart.c/.h` 实现串口初始化和 `putchar()`，`ds1302.c/.h` 与 `onewire.c/.h` 分别负责时间和温度接口。

## 如何运行与验证

在 Keil C51 打开 `1.uvproj`，核对 12 MHz 设置、串口接线和 V31/V40 板上配置后编译下载；串口工具设置 9600 bps，再发送 `time1` 或 `temp2`。原工程历史构建记录为 0 error / 0 warning，**尚无本仓库副本的串口输出截图和实物复测记录**。

## 调试问题与下一步

源码启动时调用 `Set_Time(0x23, 0x59, 0x55)`，会写入固定 RTC 时间；`Year` 也固定为 2026。因此时间输出目前是通信练习，不应描述为真实当前时间。复测时需要确认命令边界、串口丢字节情况和 DS18B20 读数，再考虑改进协议。初版保留原代码。
