# PCF8591 I²C/ADC 练习

## 项目目的

把模拟量经 PCF8591 转为数字读数，再显示为电压，练习软件 I²C 与数码管协同工作。

## 硬件平台

CT107D、IAP15F2K61S2、PCF8591 与 8 位数码管。Keil 工程目标为 `STC15F2K60S2 Series` 兼容系列；计时配置按 12 MHz 编写。

## 实现功能与技术点

- `iic.c/.h` 提供软件 I²C 和 `Read_Adc()`；`main.c` 以控制字节 `0x43` 读取模拟量。
- 将 ADC 返回值按源码中的比例换算为电压，保留两位小数并进行动态显示。
- Timer2 扫描数码管，并为周期采样提供计数。

源码入口：`main.c`；I²C 驱动：`iic.c/.h`；Keil 工程：`3.1.uvproj`。

## 如何运行与验证

在 Keil C51 打开 `3.1.uvproj`，核对板上 PCF8591 输入连接和时钟后编译下载。调整模拟输入，记录输入条件、显示数值和万用表读数作对照。原工程历史构建记录为 0 error / 0 warning；实际电压精度尚未测量。

## 调试问题与下一步

当前没有输入电压与显示结果的对照表。源码使用固定比例系数，是否符合所用参考电压与通道接线需要实测；不把静态换算写成已完成校准。
