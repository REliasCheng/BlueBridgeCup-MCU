## Hardware

- 平台：CT107D 蓝桥杯单片机竞赛训练板，资料覆盖 V31/V40。
- 板载 MCU：IAP15F2K61S2。部分 Keil 工程选择 `STC15F2K60S2 Series` 作为兼容开发目标；两者在这里不混写成同一个实际芯片。
- 常用硬件：LED、8 位数码管、独立/矩阵按键、PCF8591、AT24C02、DS18B20、DS1302、蜂鸣器和继电器。
- 我对 P0、P2、74HC138 与锁存器的理解写在 [硬件笔记](docs/hardware.md)。

## Development Environment

- 语言：C（Keil C51）。
- IDE：Keil µVision；每个项目保留独立 `.uvproj`，源码和工程配置位于同一目录。
- 下载：STC-ISP；实际主频、端口与 V31/V40 的跳线或拨码需按所用工程和开发板核对。现有多个例程按 12 MHz 配置。
- 构建产物和个人界面配置由 `.gitignore` 排除，仓库不附带工具安装包或 HEX 集合。
- 部分原始 C 文件使用 GBK 中文注释；`.gitattributes` 让 GitHub 中的文本可读，F 盘工作副本保持原有字节。

## Learning Path

当前能在仓库中直接打开的路线是：

`GPIO/LED → 数码管显示 → 按键输入 → UART 通信 → I²C/ADC 与温度传感器 → 国赛方向综合训练`

这不是“所有内容都已掌握”的清单。后续增加 EEPROM、RTC、PWM、超声波和省赛综合工程时，会附上实际实验与验证记录。详细进度见 [学习路线](docs/learning-roadmap.md)。

## Hardware Understanding

在 CT107D 上，P0 输出复用的数据；P2.5～P2.7 参与 74HC138 译码，选择不同 74HC573 锁存通道。例程常使用 `0x80` 选择 LED、`0xA0` 选择蜂鸣器/继电器、`0xC0` 选择数码管位选、`0xE0` 选择段选。数码管需要周期性更新位选与段码，LED 输出则要注意低电平有效。详见 [硬件笔记](docs/hardware.md)。

## 怎样打开工程

1. 安装 Keil C51 和相应 STC15 器件支持，打开项目目录下的 `.uvproj`。
2. 核对工程目标器件、时钟和板上拨码/跳线。V40 下载 IAP15 时，官方硬件版本说明要求 J9、J14 置于 IAP15 侧。
3. 在 Keil 中重新编译，生成 HEX 后使用 STC-ISP 下载。
4. 按各项目 README 的输入和观察点做实物检查，把结果和照片补到项目说明中。

首次下载前请以手头开发板与官方硬件说明为准；仓库不附带烧录工具。
