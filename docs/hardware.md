# CT107D 硬件理解笔记

这份笔记用于解释本仓库实验代码和开发板之间的对应关系，不是完整原理图。根据手头资料，训练板包含 V31、V40 两种版本；板载 MCU 为 IAP15F2K61S2，而 Keil 工程常选 `STC15F2K60S2 Series` 作为兼容目标。

## 从 P0 到 LED/数码管

```text
MCU P0（8 位数据）
       │
       ▼
74HC573 锁存通道 ──► LED / 蜂鸣器与继电器 / 数码管位选 / 数码管段选
       ▲
       │
P2.5、P2.6、P2.7 ──► 74HC138 译码与通道选择
```

例程中常先把数据送到 P0，再用 P2 选择锁存通道，最后释放选通信号。常见选择值及对应功能如下：

| P2 选择值 | 对应输出 |
|---|---|
| `0x80` | LED 锁存器 |
| `0xA0` | 蜂鸣器、继电器等输出 |
| `0xC0` | 数码管位选 |
| `0xE0` | 数码管段选 |

LED 为低电平有效。数码管显示要循环写入段码和位选，刷新不及时可能出现闪烁；切换位之前先关闭位选可减轻重影。仓库中的 [数码管练习](../projects/segment-display-demo/README.md)把扫描放在 Timer2 中断内。

## 在本仓库中如何用到

- [LED 练习](../projects/led-demo/README.md)：通过锁存器输出 LED 状态，也控制继电器。
- [数码管练习](../projects/segment-display-demo/README.md)：轮流选择 8 位数码管并写段码。
- [按键练习](../projects/key-demo/README.md)：从按键引脚读取输入，再改变 LED 输出。
- [国赛方向训练](../competition/national/16th-practice/README.md)：把 LED、数码管、按键和 RTC 放在同一程序里，开始面对资源和任务安排问题。

矩阵键盘与 UART1 涉及复用引脚，综合工程必须检查引脚选择和外围连接，不能仅看单个驱动是否编译通过。

## 板型与资料

V31 与 V40 的接口和下载设置有差异。手头官方《硬件版本说明》记载：V31 是绿色板、USB-B；V40 是黑色板、USB-C，部分跳线改为拨动开关。V40 下载 IAP15F2K61S2 时，J9、J14 均置于 IAP15 侧。

核对依据：CT107D `SCH_V31.pdf`、`SCH_V40.pdf`、《硬件版本说明.txt》以及 STC15 系列手册。这里没有复制这些第三方 PDF；涉及具体连线和拨码时应回查原资料及实物丝印。
