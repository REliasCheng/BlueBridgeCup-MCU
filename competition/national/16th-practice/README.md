# 国赛方向模拟训练工程

## 项目目的

把显示、按键、LED、RTC 和参数界面放进一个程序中，练习比单一外设实验更复杂的状态组织与定时任务。这里是学习阶段保留的“16届自己”工程，**不是正式比赛作品，也不是完整赛题答案**。

## 硬件平台

CT107D、IAP15F2K61S2、8 位数码管、LED、矩阵键盘、DS1302、蜂鸣器与继电器。Keil 工程选择 `STC15F2K60S2 Series` 兼容目标。

## 已实现的代码结构

- `main.c` 中有数据、参数和校准界面；显示子任务分别处理时间、液位/电压/重量等项目。
- Timer2 中断统一刷新 LED、蜂鸣器/继电器和数码管，并累计多个任务计数器。
- `Key_Task()` 读取矩阵键值、切换界面与修改参数；`Data_Task()` 从 DS1302 读取时间。
- `library.c/.h` 提供底层控制与按键函数，`ds1302.c/.h` 为 RTC 驱动。

## 如何打开与验证

在 Keil C51 打开 `16.uvproj`，先核对目标器件、12 MHz 配置、矩阵键盘连接与板上拨码，再编译下载。原工程历史构建记录为 0 error / 0 warning；这不是功能完成证明。本仓库副本还需要逐个界面、按键和输出进行板端复测。

## 调试问题与下一步

代码中 `temp`、`level`、`vol`、`wt` 有固定初值，部分界面属于显示/交互练习；不能据此宣称真实传感器测量或完整闭环控制。下一步是按实际训练题要求列功能检查表，区分已运行、占位显示与未实现项，再记录测试照片和修订提交。初版保留原始代码。
